# Landing Templates

A small shelf of reusable landing page templates by Cristobal D'Alessio. Each template lives in its own folder, is fully self-contained, and can be viewed live or copied as the starting point for a new page.

**Browse them from the home page: [index.html](index.html)** (live: `heycristobal.com/landing-templates/`)

## How to reuse one

1. Copy the template's folder into your new project.
2. Replace the copy and images; each folder's README notes the hooks, defaults, and shortcuts to know about.
3. Keep the engine code intact where a template has one (pond, rain); the interesting behaviour lives there, and the content layer is plain HTML on top.

## House rules for this shelf

- Self-contained folders: no shared assets between templates, so any folder can be lifted out on its own.
- Styling follows the Quiet Pixel guide: dark soft-purple grounds, rounded soft shapes, Space Mono, one accent per screen.
- Accessibility basics travel with each template: `prefers-reduced-motion` support, visible focus states, and real HTML content (canvas art is decorative).

## Origins

The templates grew out of the [ASCII-VISUAL-PROJECTS](https://github.com/dalecri/ASCII-VISUAL-PROJECTS) collection: the portfolio from its botanical koi landing page, Petrichor from its Rain on Glass piece, the Robin Ashe portfolio from its Terrain Flyover, the Claire Beaumont portfolio from its ASCII Aurora, and the Priya Nair portfolio from its Weather Pond. The cris-home template is the exception: not from the collection and not fictional, it is the owner's own homepage, shelved as the reference build. The sol-ragnarsdottir-map template is the other exception: it was built from the vault's own Landing Template prompt (persona, craft, city, technique), with an ASCII-textured map as the featured technique. The ida-halvorsen-bands template came from the same prompt, with hover physics as its technique. cris-handwriting is a second real-content template alongside cris-home: the owner's portfolio as a notebook page, set in the Cris Handwritten font from dalecri/handwriting. (An earlier edition of the portfolio template carried a real person's details; it was retired in favour of the persona edition and still runs as the live prototype at heycristobal.com/prototype/.) The meadow-minuit template is the shelf's first 3D piece, built from the Night Meadow prompt, a take on Marina Budarina's interactive 3D gift-card site. The marisol-ayala-weaver template is another persona build, its technique a working four-shaft weaving draft: the drawdown on its canvas is computed from real threading, tie-up, and treadling data, not drawn as decoration.
