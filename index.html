Landing Templates.

Reusable landing pages, each in its own self-contained folder. Copy one, swap the copy, ship it. Both grew out of the ASCII visual experiments, so each is alive in ways a static mockup is not.

How to reuse one

    
    
      
  1. Copy the folder into your new project. Nothing is shared between templates, on purpose.
    2. 
      
  2. Replace the copy. Sections are plain HTML; each folder's README lists the hooks and defaults.
    3. 
      
  3. Keep the engine, change the weather. The pond and rain engines take new palettes and scenes without structural changes.
