# My Dynamic Portfolio

Cristobal's own web-projects archive as one big single page (built July 2026): the whole project shelf in one scrollable index. The maximalist counterpoint to this shelf's quieter templates, kept as a reusable portfolio starting point.

Origin: built July 2026 as dalecri/my-dynamic-portfolio; shelved 2026-10-28 during the repo consolidation.

## Files

- `index.html` — everything (73,479 B).

## Dependencies

One HTML file, no build, but NOT offline-self-contained: at runtime it loads Tailwind from the Play CDN and four font families (Space Grotesk, Plus Jakarta Sans, Space Mono, JetBrains Mono) from Google Fonts, so it needs an internet connection.

## Reuse hooks

- Swap the project entries in the markup to make it anyone's archive page.
- Restyle through the embedded Tailwind config and stylesheet.
